# LAB-10 – PHP Practical Programs

## About the Project
This repository contains PHP practical programs developed as part of the Web Technology Laboratory.

## Programs Included

### 1. PHP Session Login and Logout
- Accepts username and password through a login form.
- Uses PHP sessions to store username information.
- Displays a welcome message.
- Provides a logout option to destroy the session.

**Files:** `index.html`, `welcome.php`, `logout.php`

### 2. Display Current Date, Time and Day
- Displays the current date.
- Displays the current time.
- Displays the current day using PHP's `date()` function.

**File:** `date.php`

### 3. PHP Age Verification
- Accepts the user's age.
- Checks whether the user is 18 or older.
- Displays an eligibility message.

**Files:** `age.html`, `check.php`

## How to Run
1. Install and configure a PHP server.
2. Place the LAB-10 folder in the server's web directory.
3. Start the PHP server.
4. Open the required PHP or HTML file through the local server in your browser.

## Learning Outcomes

- Implementing conditional statements.
